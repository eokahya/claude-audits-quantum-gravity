# The paper

E. O. Kahya, *Auditing a quantum gravity calculation with an AI model: corrected scalar self-mass and unchanged
late-time mode functions during inflation* (submitted to arXiv, 2026).

- [`paper.pdf`](paper.pdf): the compiled paper (65 pages).
- [`main.tex`](main.tex): the single, self-contained LaTeX source (revtex4-2), as submitted. Compile with
  `tectonic -X compile main.tex` or `pdflatex main.tex` (run twice).

The paper presents the corrected, unified computation of Kahya and Woodard, Phys. Rev. D 76, 124005 (2007) and
Phys. Rev. D 77, 084012 (2008). The full step-by-step derivations are in [`../notes/notes.pdf`](../notes/notes.pdf), and
the verification code is in [`../code/`](../code/).
